# Ark Linux

A lightweight Linux distribution based on CachyOS, with a trimmed-down KDE Plasma
desktop, a graphical installer and its own look.

- Website: https://abshar1976.github.io/
- Download: see [Releases](https://github.com/abshar1976/ark-linux/releases) (editions: KDE Plasma, Hyprland, XFCE, Cinnamon)

Made by Syed Rayyan ul Haque
([Instagram](https://www.instagram.com/ryanhq321/),
[YouTube](https://www.youtube.com/@SyedRayyanHaque762)).

Ark Linux is an independent project and is not affiliated with or endorsed by
CachyOS, Arch Linux, KDE or Chaotic-AUR.
